## ✨ Features

- ⏳ **Fluid Sand Dynamics**: Smooth animation simulating real hourglass grain flow and settling chambers.
- ⏱️ **Flexible Intervals**: Quick presets (25m Pomodoro, 15m Sprint, 5m Break) or custom time entry.
- 🔔 **Audio Cues**: Subtle notification tone on sprint completion.
- 🌘 **Zero-Distraction UI**: Deep dark aesthetic engineered to sit elegantly on a second monitor while working.
